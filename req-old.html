基本原則

  • 業主自行量測之尺寸與大小僅供參考，實際需統包方現場實際量測。
  • 油漆、浴室吊頂、磁磚、窗框、門與門框、…等的顏色及花色，請提供相關 DM、檔案或網站連結、…等，由業主挑選。
  • 若有其他更適當的方式、材料、品項、水電點位、…等，請先告知業主與討論及報價，再由業主決定與選用。
  • 任何裝修皆以不影響結構安全為原則。隔戶牆、外牆、結構牆不開橫向溝槽 ( 走地板或天花板後，垂直向上或下 )。
  • 水管與電管交錯時，電管在上、水管在下。 牆體溝槽及電線底盒與管線周圍必須水泥滿漿填實。
  • 浴室、廚房皆使用中性防霉矽利康；外窗及室外接縫使用耐候型中性矽利康。
瓦斯管線安全施工規範

打除及鑽孔等破壞性施工前，須先關閉此戶的瓦斯總閥，並先評估及標記瓦斯管路走向，接近瓦斯管線區域嚴禁使用機械電鎬重擊，須以手工具謹慎剔除；若原埋於水泥中的瓦斯管於施工中露出，需先確認是否存在鏽蝕、變形、漏氣等狀況，由合格瓦斯承裝業或有關的技術人員檢查、測漏，並提出更換或改管方式，同時通知業主討論處理方式；未經確認安全無虞不得直接封閉。

下列隱蔽工程於覆蓋前，需先拍照提供業主留存：
  • 水電配管、配電箱配線、弱電配管： 需有完整且清晰的管線走向照片。
  • 防水層施作、地板打底、蓄水測試 ( 浸水測試 )、打壓試水 ( 保壓測試 )。

所有追加、減作及材料變更，須於施工前提出書面或電子報價，述明原因、數量、單價、工期影響，經業主同意後方可施作。未經同意之追加工程，業主不負付款義務；緊急防止損害之必要處置除外，但應即時通知業主並留存照片。

一、 核心架構工程

1 大樓保護工程

  • 電梯車廂內部包覆、梯廳走道至家門口動線保護（ 防潮布、瓦楞板、木夾板三層防護 ）。
  • 保護工程施作前，請統包會同大樓總幹事，將電梯內外、梯廳、…等公共動線進行錄影 ( 拍照 ) 存證。

2 地板工程與拆除

  • 陽台磁磚不動，其餘空間舊地磚拆除見底、重新做泥作水泥砂漿打底，抓平後再鋪貼 60 cm x 60 cm 國產防滑柔光面磁磚 ( 冠軍、白馬、馬可貝里 )。
  • 鋪貼時背滿漿/膠。磁磚四個角落與四條邊緣絕不能存在空鼓。乾區單片磁磚之總空鼓面積不得超過該片面積之 10%，且不合格片數不得超過乾區總鋪貼片數之 5%。
  • 磁磚貼完且水氣大致排出並充分硬化後，進行填縫 ( 填縫顏色與磁磚相近，但不要白色 )。
  • 玄關、客廳、三個房間的磁磚要連貫，非整片的磁磚不要貼於視覺主要區域 (如走道)。兒童房木地板拆除。
  • 磁磚防滑係數若採 C.S.R·B ( 赤腳防濕滑 ) 數值應達 0.50 含以上；若採 DIN 51130 則防滑等級應為 R10 含以上。
  • 主臥房上吊櫃拆除。

3 全室水電路更新、瓦斯管線

電源
  • 全室線路更新 (太平洋電線電纜 2.0 mm、3.5 mm²、5.5 mm² 電線)、總開關使用 士林電機 NFB，其餘所有分路皆使用士林電機 NVB-50UL ( 漏電感度使用 30mA 的；漏電/過負載/短路保護 )、開關與插座使用國際牌星光系列、5.5 mm² 的插座使用國際牌星光的系列 WNF155236W ( 附門 )。 新增的插座使用單聯金屬埋入式接線盒 ( 視狀況使用加深的 )。
  • 更換全新符合現行法規之匯流排分電箱 ( 含安全封蓋板、一次側與二次側銅排、中性線與接地銅排 )。分電箱固定牢固，四周填補密實，不得有明顯孔洞與鬆動。分電箱中電線請使用合規的O型端子壓接 ( 單芯線可不壓接 )，並加上端子保護套。
  • 迴路共約 18 條 ( 含總開關共 26P，但分電箱至少需額外預留 4P 未使用供未來擴充 )、插座及開關共約 51 處，詳細資訊請見附件，指定的位置是否適合開孔開槽依師傅專業判斷，若附件標示的指定位置不建議開孔槽則請通知業主 )。L1 和 L2 兩條火線負載總電流盡量平衡。
  • 3.5 mm² 及 5.5 mm² 的線路不經由插座上的孔做串接，請用合規的 WAGO 221 系列 快速接線端子做並接，剝線的長度需符合 WAGO、星光插座與開關之要求。線材不得在牆體/地板/天花板內做續接，以一條完整無中斷的線拉到目的地 ( 插座/開關 )。絞線不得剪斷線股。火線、中性線、地線、控制線的線材顏色要依規定統一配置。
  • 開關要拉中性線。若能安全且容易連接至大樓的接地，則所有插座要拉接地線；但無論是否有接地線，皆使用三孔附接地的插座 ( 不用兩孔的 )。
  • 使用士林電機 NVB-50UL 需依原廠接線方式；每個迴路的皆需有各自獨立的中性線，不能跨迴路共用、不得回接其他迴路。亦不得繞過該迴路漏電斷路器直接接至中性銅排。電源側中性線接法依原廠接線圖及分電箱配置施作。
  • 馬桶旁免治馬桶插座，使用國際牌防雨插座 WKF2105 銀色。
  • 浴室天花板的電燈線，多拉一條中性線預留 ( 從開關拉至天花板 )。
水管
  • 冷水管使用南亞的 W 管。熱水管使用美亞或彰源的 PE 發泡被覆不鏽鋼壓接管 ( 雙壓接、SUS304、保溫被覆 )。
  • 金屬壓接管切口若有毛邊，務必使用倒角器或刮刀修掉毛邊。
  • 盡量減少非必要的水管接續點，以減少漏水點。 PVC 續接請用接頭，不要用火烤擴口，且連接點 10 公分內不要火烤。
  • 浴室天花板入水後，沿牆壁下至走地板裡 ( 或房間門框上的牆面裡 )，經廚房再由系統廚具背面或左側的牆壁內向上，穿牆至陽台，於陽台可走明管或暗管 ( 但不要動到地板或者地板向上 80 cm 內的牆壁磁磚及防水 )。於陽台預留全戶淨水軟水與加壓馬達管線 ( 要留旁通 )。然後淨水再由陽台回到廚房與浴室。
  • 陽台水管、水龍頭配置的位置，需再與業主討論，避免阻擋熱水器、洗烘衣機擺放。
  • 從浴室天花板去陽台、以及從陽台回室內這兩條主幹線，至少使用 6 分管 ( 或跟入戶水管的管徑一樣 )。
  • 熱水器的冷水進入及熱水出水，使用 6 分管 ( 若熱水器用 4 分頭，再用 “管螺紋變徑接頭” 轉為 4 分後連接熱水器)。這條 6 分熱水主管拉至室內後，分接四分管出來給廚房，接著繼續 6 分管通往浴室，浴室那再個別分接 4 分管給蓮蓬頭、洗手台。
  • 陽台增加一個熱水出水龍頭。
  • 廚房原本由牆壁孔出水，改為檯面下角閥出水，以對接系統廚具，原出水孔廢棄填平。
  • 全室給水管需依照管材原廠規範進行打壓試水 ( 保壓測試 )，壓力須逐步升壓達至規範壓力值，並維持 60 分鐘不掉壓、不漏水。
排水：
  • 拆除時及拆除後，所有浴室、廚房及陽台之排水管口應立即以適當保護塞或保護蓋封閉，避免施工期間異物掉入管內造成阻塞，待安裝落水頭及排水測試前再行拆除；完工前再次確認排水暢通。
  • 全屋水泥打底與鋪設新地板前，需先檢查舊有排水管（ 浴室、廚房、陽台 ）確認是否完全順暢。
地漏：
  • 浴室使用防臭地漏。
  • 廚房原本地板走中間的地漏，改成用 “預留排水口” 暫時性封閉 ( 密閉式面蓋 )。
瓦斯：
  • 待與統包確認瓦斯管線的處理方式。
  • 完工後需確認瓦斯管線可正常使用並且無洩漏。

4 弱電

  • 三間房間增加網路線槽搭配單聯埋入式加深接線盒 ( 詳細資訊請見附件 )，預拉二條 CAT.6 UTP ( 網路線材業主自備 ) 及一條尼龍拉線 ( 留水線 ) ，三個房間的接線盒出線預留至少 50 cm 裸線。
  • 所有網路線匯集至客廳電視牆面 ( 詳細資訊請見附件 )，從一個金屬雙聯埋入式加深接線盒出線 ( 共 6 條網路線、3 條尼龍水線 )，出線的網路線預留至少 300cm 的裸線。
  • 先確認入戶電話線的源頭， 並將電話插座改到客廳電視牆面中間偏右 ( 詳細資訊請見附件 )。
  • 管線走 6 分 CD 管或 PVC 管，弱電管與強電 (110V/220V) 不塞同一條線管，弱電與強電之間要有間隔 ( 非垂直交錯時盡量間隔 6 cm 含以上 )。管路彎曲度及轉灣數應確保線材可抽換。
  • 電話線路若有動到插座與管線，則需測通。

5 浴室翻新

  • 舊有拆除見底、水泥砂漿打底、防水施作一底兩度高強度彈性水泥 (防水高度做到天花板吊頂高度，每道工序須完全乾透且採垂直與水平十字交叉法塗刷)、鋪貼壁磚與地磚。
  • 地面磁磚與牆面角落的磁磚皆不能有空鼓狀況。
  • 浴室門與框換新 ( 大約 75cm寬 x 200cm 高 )： 使用塑鋼門，門框採溼式施工 ( 傳統前置門框 )。
  • 天花板換新 ( 日本麗仕 矽酸鈣板+接縫 AB 膠+防潮批土+封閉底漆+2道防水/防霉面漆 )、預留維修孔、暖風機孔尺寸為 30x30cm 需吊筋及角材之類的材料加強承重與鎖固；浴室上方有梁柱，因此暖風機位置需注意上方是否有足夠空間放暖風機及過風管；維修孔位置需注意是否有空間更換設備、開關入水閥。
  • 使用國產磁磚 ( 冠軍、白馬、馬可貝里 )，牆面用 30cm x 60cm 磁磚、地磚用 30 cm x 30 cm 防滑磁磚 ( 防滑係數若採 C.S.R·B 赤腳防濕滑 則數值應達 0.60 含以上 )。
  • 浴室全區地板、所有的結構與易漏水交界處 ( 含地壁接縫、陰陽角、管線周圍、落水頭、門檻止水墩周邊 ) 皆須鋪貼做防水防裂用的六角網/玻纖網/不織布之類的材料進行加強。網材施作時須確實以防水漆 ( 彈性水泥 ) 刷平壓實並完全包覆於塗層中，網材不可浮起、產生皺褶或空鼓脫層。
  • 舊有的防水層要去除乾淨。貼磁磚時牆面與地面的磁磚縫要對齊。浴室門檻止水墩下面多刷一層防水。
  • 門檻下方，用無收縮水泥灌一道高於室內地坪至少 1 ~ 2 cm 的泥作止水墩，防水層須包覆止水墩，再安裝門檻。
  • 貼磚前需先進行蓄水測試 ( 浸水測試 )，靜置至少 48 小時。
  • 牆壁磁磚陽角使用鋁製/不銹鋼製小圓角收邊條。
  • 洩水坡度： 施作連續洩水坡度，淋浴區 1~1.5% 坡度，馬桶及門口區域為 1% 坡度。
  • 淋浴區冷熱水出水口，使用龍頭水平定位器等工具進行固定，確保水平及中心距為標準 15 cm。貼磚完成後，管口不可凸出磁磚完成面，需平齊或內凹至多不可超過 5 mm。
  • 落水頭 ( 防臭地漏 )：蓋板也要方型的，不要傳統外方內圓的款式。 PVC 排水管於泥作打底前不得切齊樓板，應預留適當高度，防水層必須完整包覆管根及管外壁。PVC 排水管之預留高度應依所採用落水頭產品施工規範調整，使落水頭底座 ( 導水管 ) 可完全插入 PVC 排水管內，不得懸空或插入不足。落水頭周圍應以無收縮水泥或聚合物修補砂漿填實固定，防水層須與落水頭法蘭 ( 或底座 ) 形成連續完整之防水構造，避免積水滲入砂漿層造成側漏。
  • 管道間防臭封堵：浴室與管道間之牆上孔洞封填至上層樓板底 ( 使用防火發泡劑+矽酸鈣板之類的，不使用水泥與磚頭封死 )；增加一個硬質風管或套管以做為排風使用，周圍以防火發泡劑+矽酸鈣板之類的填塞，且風管或套管應微向下傾斜至管道間，室內端管子高於管道間，避免凝結水倒灌。
  • 浴室的牆面配水電管線時，原則上採直上直下，避免未來鑽破。
衛浴設備採購與安裝：
以下衛浴設備，由「統包採購與安裝」：
  • 單體式馬桶 ( TOTO CW288SGUR )，需請統包確認管距及空間是否能安裝此型號馬桶，亦需避免馬桶卡到門或沖水把手卡面盆及浴櫃。
  • 面盆 ( TOTO L710CSRETW )。
  • 左開浴櫃 ( 白色系或淡灰色系，PVC 發泡防水 50寬x45深，採面盆直接安裝於浴櫃之形式，不另設檯面板 )。
以下衛浴設備，由「業主自行採購，統包協助安裝」：
  • 暖風機 ( 台達電 VHB30BCMRT-A )
  • 免治馬桶座 ( TOTO TCF33161GTW )
  • 鏡子/鏡櫃、毛巾架、角落吊架/吊櫃、蓮蓬頭昇降桿、無鉛淋浴龍頭 ( LOLAT、HCG、TOTO )。

6 窗戶 ( 3房間窗 + 1 陽台窗 + 1 落地窗 + 1 浴室窗 + 2窗型冷氣孔 )

  • 除落地窗為溼式施工外，其餘舊窗皆採用乾式包框工法；鋁框內所有中空夾縫需灌入疏水型 PU 防水發泡劑或隔音棉等填滿。室外側的窗框與水泥或磁磚交接處需以耐候型矽利康密實填縫。
  • 橫拉窗皆使用正新門窗 ( 大和器系列 PL-892 / PL-192)。
    • 主臥房橫拉窗 ( 約 203cm寬 x 126cm高 )： 5+5mm 膠合雙面強化玻璃。
    • 次臥房橫拉窗 ( 約 203cm寬 x 95cm高 )： 5+5mm 膠合雙面強化玻璃。
    • 小孩房橫拉窗 ( 約 159cm寬 x 132cm高 )： 5+5mm 膠合雙面強化玻璃。
    • 陽台橫拉窗 ( 約 171cm寬 x 97cm高 )： 4+4mm 膠合雙面強化玻璃。
    • 浴室橫拉窗 ( 約 99cm寬 x 73cm高 )： 4+4mm 膠合雙面強化玻璃。
    • 主臥原窗型冷氣孔 ( 約 60cm寬 x 55cm高 )： 改為橫拉窗，使用 5+5mm 膠合雙面強化玻璃。
    • 小孩房原窗型冷氣孔 ( 約 69cm寬 x 56cm高 )： 改為固定窗，使用 5+5mm 膠合雙面強化玻璃。
    • 落地橫拉窗 ( 約 118cm寬 x 208cm高 )： 4+4mm 膠合雙面強化玻璃，採溼式施工，降低一半之門檻高度，盡量不破壞陽台防水。
  • 窗戶需配合「冷氣室外機管線、排油煙機的排風管 ( 5.5 吋 )」以鋁製方管之類的材料 ( 不要用塑鋁板那類輕薄易損壞的 )，預先開孔供管線穿過。
  • 包框前需檢查舊下框與牆體連結的固定力與整體結構承重，並做適當加強與固定。

7 房間門換新

  • 配合全室地板打除工程，拆除原有三個房間的舊門框與門片 ( 含外露的舊門框大約 90cm寬 x 200cm 高 )。
  • 後裝式門框 ( 乾式施工 )、門片使用實芯木門/實木複合門 ( 如「橙門」的 「實芯門-KD批批板系列」）、門板下方需內嵌自動升降防塵隔音條、門擋、鎖具 ( 優先使用靜音款 )。
  • 門框須安裝垂直方正，門片開關順暢，不得自行開啟或關閉，門縫均勻且不得明顯歪斜。灌漿或 PU 填縫須飽滿無空鼓。

8 油漆工程

  • 全室牆面： 使用「立邦 淨味兒童漆」。
  • 全室天花板： 使用立邦的無毒乳膠漆（平光）。
  • 所有漆面先刷「得利 室內專用水性全效封閉底漆」後再刷兩道面漆。
  • 針對裂縫、廚房去除磁磚後之牆面、開孔、開槽處進行局部修補與基礎批土、打磨順平。
  • 全室不做傳統踢腳板油漆，牆面舊有的深色踢腳板油漆，先用封閉底漆阻絕後，再覆蓋至少三道牆面漆完全蓋掉。
  • 批土打磨及油漆前先卸除電燈、開關、插座、面板後再施作。

9 空調管線預留

  • 會同冷氣廠商，先評估室內外機安裝位置、電源、冷媒管路線、排水路線 ( 打溝埋管、原大樓冷氣專用排水管 )。
  • 由統包協助 3 台舊窗型冷氣、1 台直立式洗衣機的清運，並提供廢四機回收聯單。

10 廚房

  • 排油煙機風管： 延伸至防盜鐵窗外，需有室外防雨罩，並於窗框開孔處附近安裝逆止風門。
  • 廚房區域需施作基本防水，防水做到磁磚完成地面向上至少 30cm，且牆角、管根、排水口、穿牆孔等處，須鋪貼做防水防裂用的六角網/玻纖網/不織布之類的材料進行加強。網材施作時須確實以防水漆 (彈性水泥) 刷平壓實並完全包覆於塗層中，網材不可浮起、產生皺褶或空鼓脫層。
  • 落水頭 ( 防臭地漏 )：同浴室翻新裡針對落水頭的需求。
  • 廚房上吊櫃拆除。
  • 牆面磁磚打除，並水泥粉光、批土後改上乳膠漆。
