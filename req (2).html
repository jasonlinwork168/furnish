基本原則

  • 業主自行量測之尺寸與大小僅供參考，實際尺寸由統包方現場量測確認。
  • 油漆、浴室吊頂、磁磚、窗框、門與門框、…等的顏色及花色，請提供相關 DM、檔案或網站連結、…等，由業主挑選。
  • 若有其他更適當的方式、工法、材料、品項、水電點位、…等，請先告知業主並經雙方確認。
  • 任何裝修皆以不影響結構安全為原則。隔戶牆、外牆、結構牆不開橫向溝槽 ( 走地板或天花板後，垂直向上或下 )。
  • 水管與電管交錯時，電管在上、水管在下。 牆體溝槽及電線底盒與管線周圍必須以無收縮/抗裂材料填實。
  • 浴室、廚房皆使用中性防霉矽利康；外窗及室外接縫使用耐候型中性矽利康。
  • 除浴室外，其餘空間不加做吊頂。
瓦斯管線安全施工規範

打除及鑽孔等破壞性施工前，須先關閉此戶的瓦斯總閥，並先評估及標記瓦斯管路走向，接近瓦斯管線區域嚴禁使用機械電鎬重擊，須以手工具謹慎剔除；若原埋於水泥中的瓦斯管於施工中露出，需先確認是否存在鏽蝕、變形、漏氣等狀況，由合格瓦斯承裝業或有關的技術人員檢查、測漏，並提出更換或改管方式，同時通知業主討論處理方式；未經確認安全無虞不得直接封閉。

下列隱蔽工程於覆蓋前，需先拍照提供業主留存：
  • 水電配管、配電箱配線、弱電配管： 需有完整且清晰的管線走向照片。照片需標示空間名稱、拍攝方向、以牆角或地面為基準搭配捲尺或尺寸標示，以便於日後定位。
  • 防水層施作、地板打底、蓄水測試 ( 浸水測試 )、打壓試水 ( 保壓測試 )。

所有追加、減作及材料變更，須於施工前提出書面或電子報價，述明原因、數量、單價、工期影響，經業主同意後方可施作。未經同意之追加工程，業主不負付款義務；緊急防止損害之必要處置除外，但應即時通知業主並留存照片。

一、 核心架構工程

1 大樓保護工程

  • 電梯車廂內部包覆、梯廳走道至家門口動線保護（ 防潮布、瓦楞板、木夾板三層防護 ）。
  • 保護工程施作前，請統包會同大樓總幹事，將電梯內外、梯廳、…等公共動線進行錄影 ( 拍照 ) 存證。

2 地板工程與拆除

  • 陽台磁磚不動。玄關、客廳、三個房間、廚房的舊地磚拆除見底、重新做泥作水泥砂漿打底，抓平後再鋪貼 80x80cm 國產防滑柔光面磁磚 ( 冠軍、白馬、馬可貝里 )。
  • 磁磚完成面應平整、牢固、對縫，磚縫順直且寬度均勻，不得有明顯空鼓、高低差、裂損、翹動、鬆脫或踩踏異音；於黏著材料達養護時間後，以外觀、踩踏及敲擊方式抽驗，磁磚中央、四角、邊緣、主要通行動線及集中受力位置不得有明顯、集中或連續性空鼓，亦不得有影響黏著、承載、使用安全或耐久性之瑕疵。
  • 填縫時間依黏著材料原廠規定之養護時間施作 ( 填縫顏色與磁磚相近，但不要白色 )。
  • 玄關、客廳、三個房間的磁磚要連貫，非整片的磁磚不要貼於視覺主要區域 (如走道)。
  • 磁磚防滑係數若採 C.S.R·B ( 赤腳防濕滑 ) 數值應達 0.50 含以上；若採 DIN 51130 則防滑等級應為 R10 含以上。
  • 拆除：主臥房上吊櫃、系統廚具、小孩房木地板、廚房上吊櫃。

3 全室水電路更新、瓦斯管線

電源
  • 業主提供各點位預定設備及使用需求。承攬商應依設備額定負載、同時使用情境、配線方式、管內導線數、線路長度、電壓降及保護協調、兩相負載及總電流平衡、評估點位是否適合開孔及開槽，提出最終迴路、線徑、斷路器容量與相別配置，經雙方確認施作內容與方式及報價確認後施工。
  • 全室線路更新 ( 太平洋電線 )、總開關使用 士林電機 NFB，其餘所有分路皆使用士林電機 NVB-50UL ( 漏電感度 30mA；啟斷容量 10 kA；漏電/過負載/短路保護 )、開關與插座使用國際牌星光系列、5.5 mm² 的插座使用國際牌星光系列 WNF155236W ( 附門 )。 新增的插座使用單聯金屬埋入式接線盒 ( 視狀況使用加深的 )。
  • 更換全新符合現行法規之匯流排分電箱，分電箱需固定牢固且四周填補密實，不得有明顯孔洞與鬆動。分電箱中電線請使用合規的端子壓接 ( 單芯線可不壓接 )，並加上端子保護套。
  • 迴路共約 16 條 ( 含總開關共 24P，但需再額外預留 4P 供未來擴充 )、插座與開關共約 47 處，詳細資訊請見附件。
  • 所有導線之接續、分支點僅可設於可開啟檢修之插座/開關接線盒或配電箱內；導線管內、牆體、地坪及其他完工後不可檢修處不得設置接頭或續接。
  • 剝線及接線不得剪除線股、削減導體截面。且各類導線顏色應依現行規定統一配置。
  • 各燈具開關盒均應預留中性線，不論是否與插座同盒。
  • 若有入戶接地線，則各點位皆需拉接地線。原則上皆使用三孔附接地插座 ( 不用兩孔的 )；若現場確認無有效接地來源，應由統包提出符合現行規定之處理方案，經業主確認後施工，不得自行將接地孔接至中性線。
  • 使用士林電機 NVB-50UL 需依原廠規範接線方式；每個迴路皆須有各自獨立的中性線，不能跨迴路共用、不得回接其他迴路。亦不得繞過該迴路漏電斷路器直接接至中性銅排。
  • 廚房的 220V 插座請拉三線 ( L1, L2, 中性線 )，若有接地則拉四線；拉中性線是為了保留未來改為 110V 使用，中性線請先絕緣保護後留置於插座的接線盒中。
  • 馬桶旁免治馬桶插座，使用國際牌防雨插座 WKF2105 銀色。
  • 浴室天花板上方 ( 維修孔附近 )，預留一組 110V 明盒雙插座 ( 需持續供電，不與電燈開關連動。明盒不需鎖固但線要夠長不要懸空掛著 )。
燈具
  • 保留並沿用： 客廳燈、三個房間燈、浴室燈、廚房燈。
  • 換新燈 ( 業主自備，統包代安裝 )： 玄關燈、陽台燈、走道燈 ( 廚房至浴室間的走道 )。
水管
  • 冷水管使用南亞的 W 管。熱水管使用 PE 發泡被覆不鏽鋼壓接管 ( SUS304、保溫被覆 )。
  • 盡量減少非必要的水管接續點，以減少漏水點。 PVC 續接請用接頭，不要用火烤擴口。
  • 浴室天花板入水後，於陽台預留全戶淨水軟水的進水、出水、旁通管路，淨水軟水後的管路再由陽台回到廚房與浴室。管線之路徑與位置由統包方評估，經雙方確認施作內容與方式及報價確認後施工。唯管徑與分支配置應避免造成明顯壓降。
  • 廚房原本由牆壁孔出水，改為檯面下角閥出水，以對接系統廚具，原出水孔廢棄填平。
  • 全室給水管需依照管材原廠規範進行打壓試水 ( 保壓測試 )，測試前應完成排氣並逐步升壓至規範壓力值，穩壓時間、保壓時間 ( 未規範則至少 30 分鐘 ) 及容許壓降依原廠規範；需確定無任何滲漏或接頭異常，並提供測試前後含壓力錶、日期及位置之照片紀錄。
瓦斯：
  • 待與統包確認瓦斯管線的處理方式。完工後需確認瓦斯管線可正常使用並且無洩漏。

4 弱電

  • 三間房間增加網路配管搭配單聯埋入式加深接線盒 ( 詳細資訊請見附件 )，每個房間拉二條 CAT.6 UTP ( 網路線材業主自備 ) 及一條尼龍引線，三個房間的接線盒出線預留至少 50 cm 餘長。
  • 所有網路線匯集至客廳電視牆面 ( 詳細資訊請見附件 )，採足以容納所有管路及線材之多聯深型出線盒出線 ( 共 6 條網路線、3 條尼龍引線 )，網路線出線至少預留 300cm 餘長。最終出線盒數量與尺寸及管路配置由統包提出，經雙方確認施作內容與方式及報價確認後施工；不得為配合單一雙聯盒而壓折、擠塞線材。
  • 先確認入戶電話線的源頭，並將電話插座改到客廳電視牆面中間偏右 ( 詳細資訊請見附件 )。
  • 管線走 6 分 CD 管或 PVC 管，弱電管與強電 (110V/220V) 不塞同一條線管，弱電與強電之間要有間隔 ( 平行配置時原則上保持至少間隔 5cm 含以上 )。管路彎曲半徑與轉彎數應確保線材可抽換。
  • 電話線路若有動到插座與管線，則需測通。

5 浴室翻新

  • 舊有拆除見底 ( 舊有防水層去除乾淨 )、水泥砂漿打底、防水層至少一底兩度，且不得低於選用產品原廠規定之塗布量、乾膜厚度、重塗間隔及養護時間。防水高度做到天花板吊頂高度。鋪貼壁磚與地磚。
  • 地面磁磚、地壁交接處 ( 陰角 )、以及設備鑽孔區之磁磚皆不得有空鼓狀況；其餘牆面磁磚不得有明顯、集中或連續性空鼓，且不得有影響設備固定、黏著、使用安全或耐久性之空鼓。
  • 浴室門與框換新 ( 大約 75cm寬 x 200cm 高 )： 使用塑鋼門，門框採溼式施工 ( 傳統前置門框 )。
  • 天花板換新 ( 日本麗仕 矽酸鈣板+接縫 AB 膠+防潮批土+封閉底漆+2道防水/防霉面漆 )、預留維修孔、暖風機孔尺寸為 30x30cm ( 需加強暖風機處承重與鎖固 )。浴室上方有梁柱，因此暖風機位置需注意上方是否有足夠空間放暖風機及排風管；維修孔位置需注意是否有空間更換設備、操作進水閥。
  • 使用國產磁磚 ( 冠軍、白馬、馬可貝里 )，牆面用 30cm x 60cm 磁磚、地磚用 30 cm x 30 cm 防滑磁磚 ( 防滑係數若採 C.S.R·B 赤腳防濕滑 則數值應達 0.55 含以上 )。
  • 浴室全區地板、所有易漏水交界處 ( 含地壁接縫、陰陽角、管線周圍、落水頭、門檻止水墩周邊、基材交界與易裂易滲部位 ) 應依選用防水材料原廠系統工法，以玻纖網、不織布或其他相容之補強材料加強。補強材料須壓實並完整包覆於防水塗層內，不得浮起、皺褶、空鼓或脫層，牆面一般完整區域不要求全面滿鋪補強網材。
  • 浴室門檻止水墩下面多刷一層防水。門檻下方，用無收縮水泥灌一道高於浴室完成地坪至少 1 ~ 2 cm 的泥作止水墩，防水層須包覆止水墩，再安裝門檻。
  • 貼磚前需先進行蓄水測試 ( 浸水測試 )，靜置至少 24 小時。
  • 貼磁磚時牆面與地面的磁磚縫要對齊，若因洩水坡度、落水頭或現場尺寸無法完全對齊者，應事前與業主確認。牆壁磁磚陽角要收邊 ( 不能易崩裂或銳角 )或使用鋁製/不鏽鋼製小圓角收邊條。
  • 淋浴區冷熱水出水口應使用水平定位器或其他等效工具定位。兩出水口應保持水平，端面位於同一平面，出水方向垂直於完成牆面。中心距以150 mm為施工基準，並應符合所選龍頭原廠安裝尺寸及容許公差。貼磚完成後，出水口端面不得凸出磁磚完成面，宜與完成面平齊；如需內凹，原則上不得超過 5 mm。原廠另有規定者，依原廠規定施作。
  • 落水頭 ( 防臭地漏 )：蓋板也要方形的，不要傳統外方內圓的款式。 PVC 排水管之預留高度應依所採用落水頭產品施工規範調整，使落水頭底座 ( 導水管 ) 可完全插入 PVC 排水管內，不得懸空或插入不足 ( 或依原廠施工規範 )。防水層必須完整包覆管根及管外壁，落水頭周圍應填實固定，防水層須與落水頭法蘭 ( 或底座 ) 形成連續完整之防水構造，避免積水滲入砂漿層造成側漏。
  • 管道間防臭封堵：浴室與管道間之牆上孔洞封填至上層樓板底 ( 使用防火發泡劑+矽酸鈣板之類的，不使用水泥與磚頭封死 )；增加一個硬質風管或套管作為排風使用，周圍以防火發泡劑+矽酸鈣板之類的填塞，且風管或套管應微向下傾斜至管道間，風管應朝排氣端保持適當向下坡度，避免凝結水回流室內。此項施工方式由統包相關專業人員提出方案，經雙方確認施作內容與方式及報價確認後施工。

6 窗戶 ( 3房間窗 + 1 陽台窗 + 1 落地窗 + 1 浴室窗 + 2窗型冷氣孔 + 2客廳窗 )

  • 除落地窗為溼式施工外，其餘舊窗皆採用乾式包框。
  • 包框之新舊框間之中空縫隙應依原廠指定工法，使用適合之填充、背襯及密封材料完整處理，不得留有明顯空腔。室外側接縫與交接處應使用背襯材料搭配耐候型中性矽利康形成連續防水接縫。需先檢查既有窗框四周狀況、牆體連結的固定力與整體結構承重，確認足以承受新窗自重及使用時之風壓。
  • 優先採正新或錦鋐門窗。但請統包推薦看是否有比此兩個品牌性價比更佳的其他選擇，以耐用、維修找得到人、氣密與隔音、兒童防墜器為主要考量。實際使用之品牌於雙方確認內容及報價後施工。
    • 主臥房橫拉窗 ( 約 203cm寬 x 126cm高 )： 5+5mm 膠合雙面強化玻璃。

7 房間門換新

  • 配合全室地板打除工程，拆除原有三個房間的舊門框與門片 ( 含外露的舊門框大約 90cm寬 x 200cm 高 )。
  • 後裝式門框 ( 乾式施工 )。門片使用木質實芯門 ( 如： 橙門 的 實芯門-KD批批板系列 或同等品 )，門片區域須以實木條、實木塊、實木拼接板等木質實芯材料實質填充，不得使用蜂巢紙、紙芯、中空結構或僅門片周邊設置木框而中央為空心或紙芯之結構。門片下緣需內嵌自動升降防塵隔音條、門擋、靜音門鎖。
  • 門框須安裝垂直方正，門片開關順暢，不得自行開啟或關閉，門縫均勻且不得明顯歪斜。門框依所選門組原廠工法固定，框體與牆面間應填充飽滿、固定牢固，不得有鬆動、明顯空腔或收邊開裂。

8 油漆工程 ( 不含浴室、磁磚面 )

  • 全室牆面： 使用「立邦 淨味兒童漆」。
  • 全室天花板： 使用「立邦 淨味5合1平光內牆乳膠漆」。
  • 所有漆面皆需先刷「得利 室內專用水性全效封閉底漆」後再刷兩道面漆 ( 若此底漆與面漆不相容，或可能產生附著不良、起泡或色差問題，則請事先經雙方確認施作內容與方式及報價確認後施工 )。
  • 針對開孔開槽處、局部裂縫或破損、廚房去除磁磚後之牆面、泥作修補處，進行修補與批土、打磨順平再上漆。在室內一般燈光及自然光照射下，牆面需無明顯溝槽痕跡、視覺斷層、修補陰影或色差。
  • 全室不做傳統踢腳板油漆，牆面舊有的深色踢腳板改刷「立邦 淨味兒童漆」，需以適當工法施作至完全遮蓋原有深色踢腳線漆，完工後不得透底或返色。
  • 批土打磨及油漆前先卸除電燈、開關、插座、面板後再施作。

9 空調管線預留

  • 由統包協助會同冷氣專業人員，先評估室內外機安裝位置、電源、冷媒管路線、排水路線 ( 打溝埋管、原大樓冷氣專用排水管 )，經雙方確認施作內容與方式及報價確認後施工。唯隔戶牆、外牆、結構牆不開橫向溝槽。
  • 冷凝水排水管應維持必要坡度，封閉前完成通水試驗並拍照記錄。
  • 由統包協調冷氣業者或合法回收業者，負責3台舊窗型冷氣及1台直立式洗衣機之安全拆除、搬運與回收。回收完成後，應提供冷氣機的廢四機回收聯單。

10 廚房

  • 排油煙機風管： 延伸至防盜鐵窗外，需有室外防雨罩，並於窗框開孔處附近安裝逆止風門。
  • 廚房地板走道中間的地漏排水孔保留，改採可開啟維修之密閉式面蓋封閉。
  • 牆面磁磚打除，並水泥粉光、批土後改上乳膠漆。
